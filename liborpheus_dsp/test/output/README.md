# Test WAV Output

Generated by test suites. WAV files are **not** checked into git (see `.gitignore`).

## File Naming Convention

| Prefix | Description |
|--------|-------------|
| `cpp_engine_<name>.wav` | C++ full-chain render (orpheus_engine_process) per Plaits engine |
| `cpp_raw_<name>.wav` | C++ raw render (plaits::Voice::Render directly, no mixing) per engine |
| `jsyn_engine_<name>.wav` | Kotlin/JSyn full-chain render (DspVoice + ADSR envelope) per engine |
| `jsyn_raw_<name>.wav` | Kotlin raw render (PlaitsEngine.render directly, no DspVoice) per engine |
| `cpp_single_voice_c4.wav` | C++ single voice C4 scenario |
| `cpp_4voice_chord.wav` | C++ 4-voice chord scenario |
| `cpp_voice_reverb.wav` | C++ voice + reverb scenario |
| `jsyn_single_voice_c4.wav` | JSyn single voice C4 scenario |
| `jsyn_4voice_chord.wav` | JSyn 4-voice chord scenario |
| `jsyn_voice_reverb.wav` | JSyn voice + reverb scenario |

## Known Differences Between C++ and JSyn Renders

- **Sample rate**: C++ renders at 48000 Hz; JSyn at 44100 Hz.
- **Gain staging**: C++ Plaits outputs int16 scaled by `(out+aux) * 0.5 * inv_32768`. JSyn applies per-engine `outGain`. Level ratio is ~10x for dry voices.
- **Envelope**: C++ uses Plaits' internal LPG (decay param). JSyn uses DspVoice's external ADSR (full-chain renders only).
- **Soft limiting**: JSyn applies `tanh` saturation above 0.5f. C++ does not.

## Generate C++ Snapshots

```bash
cd liborpheus_dsp
cmake --build build
build/orpheus_dsp_test
```

## Generate JSyn Snapshots and Run Comparison

```bash
# All snapshot tests (allEngines, allEnginesRaw, crossEngineComparison, normalizedComparison)
./gradlew :core:dsp-engine:jvmTest --tests "org.balch.orpheus.core.audio.dsp.JsynSnapshotTest"

# Individual tests
./gradlew :core:dsp-engine:jvmTest --tests "org.balch.orpheus.core.audio.dsp.JsynSnapshotTest.allEngines"
./gradlew :core:dsp-engine:jvmTest --tests "org.balch.orpheus.core.audio.dsp.JsynSnapshotTest.allEnginesRaw"
./gradlew :core:dsp-engine:jvmTest --tests "org.balch.orpheus.core.audio.dsp.JsynSnapshotTest.crossEngineComparison"
./gradlew :core:dsp-engine:jvmTest --tests "org.balch.orpheus.core.audio.dsp.JsynSnapshotTest.normalizedComparison"
```

## Compare

Open any audio editor (e.g. Audacity) and import matching pairs:

- `cpp_engine_virtual_analog.wav` vs `jsyn_engine_virtual_analog.wav` — full chain
- `cpp_raw_virtual_analog.wav` vs `jsyn_raw_virtual_analog.wav` — raw engine only

The `crossEngineComparison` test prints a summary table of RMS, peak, and JSyn/C++ level ratios.
The `normalizedComparison` test prints zero-crossing rate and crest factor after RMS normalization.
